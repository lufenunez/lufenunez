## 🚀 Proyectos destacados

### [AVALID](https://github.com/lufenunez/AVAlid) · Validación de documentos con IA y OCR
Plataforma web para **AVA Montajes Industriales** que automatiza la recepción y validación de documentos laborales en su proceso de contratación. Proyecto universidad–empresa con cliente real: **🏆 2° lugar y premio de la empresa.**

- Pipeline asíncrono de análisis documental de 8 etapas: OCR (Tesseract, EasyOCR), clasificación (TF-IDF y reglas) y validación cruzada.
- Microservicios: sistema central en Laravel + servicio de análisis en Python (FastAPI), con colas y envío masivo de invitaciones vía API de Gmail.
- PostgreSQL multi-schema y control de acceso por roles.

`Laravel` `React` `TypeScript` `Python` `FastAPI` `Scikit-learn` `PostgreSQL` `Redis` `Docker`

> El código es propiedad de la empresa, así que el repositorio muestra la arquitectura y capturas del sistema.

### [Antiguas Vanguardias](https://www.antiguasvanguardias.cl) · Sitio web de mi cuarteto
Sitio en producción con cartelera de conciertos, repertorio en PDF siempre actualizado y panel de administración privado. Las fechas de los conciertos Candlelight se importan automáticamente cada día desde Fever.

`TypeScript` `Node.js` `Turso (libSQL)` `Vercel`

### [HabilProf](https://github.com/lufenunez/HabilProf) · Gestión de habilitaciones profesionales
Sistema web para que los profesores del Departamento de Ingeniería Informática gestionen proyectos de título y prácticas de los alumnos, con sincronización automática desde la base de datos de la universidad.

`Laravel` `Vue 3` `Inertia.js` `Tailwind CSS` `PostgreSQL`
